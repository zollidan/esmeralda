# esmeralda-ru-api-fetcher

CLI-утилита на Go для автоматического сбора футбольной статистики с [api.api-sport.ru](https://api.api-sport.ru) и сохранения результатов в Excel-файл.

---

## Как работает

1. Запрашивает у пользователя дату (в формате `DD.MM.YYYY`).
2. Получает список футбольных матчей на эту дату.
3. Для каждого матча параллельно загружает историю матчей обеих команд (до 20 горутин одновременно).
4. Вычисляет статистику: очные встречи (H2H), домашние/выездные серии, тоталы голов.
5. Записывает все строки в `.xlsx`-файл, сохраняя порядок матчей.

---

## Запуск

```bash
go run ./cmd/main.go --token=YOUR_API_TOKEN
```

**Параметры:**

| Флаг      | Обязательный | Описание                       |
| --------- | ------------ | ------------------------------ |
| `--token` | да           | API-токен для api.api-sport.ru |

После запуска программа спрашивает дату в stdin:

```
Введите дату (DD.MM.YYYY): 01.03.2026
```

## Выходной файл

Файл сохраняется как `esmeralda-ru.xlsx` в текущей директории.  
Первая строка — заголовки, каждая последующая — один матч.

## Структура проекта

```
cmd/
  main.go                 — точка входа, разбор флагов, запуск пайплайна
internal/
  api/
    client.go             — HTTP-клиент api.api-sport.ru
    matches.go            — методы получения матчей и фильтрации
    models.go             — структуры ответов API
  config/
    config.go             — конфигурация (флаги, URL, имя файла)
  export/
    excel.go              — StreamWriter для записи в .xlsx
    models.go             — (пустой, Row перенесён в stats)
  processor/
    processor.go          — параллельный сбор данных по матчам
  stats/
    calculator.go         — вычисление H2H / home / away / goals статистики
    column.go             — определение столбцов Excel и метод ToSlice()
    models.go             — типы Row, TotalStats, GoalStats, MatchStats
  utils/
    date.go               — парсинг даты из stdin
```
